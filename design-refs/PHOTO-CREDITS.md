# P11 photo credits

Every photo shipped in `apps/web/public/photos/` is public domain —
**PDM** (Public Domain Mark) or **CC0** — sourced through the Openverse API
(`license=cc0,pdm` only), curated by eye on the contact sheets
`sheet-a…e.png` in this folder, then resized to max 1280px / JPEG q82.

License terms require no attribution; this file (and the picks JSON next to
it) records provenance as a project rule — see `docs/DESIGN.md` §7/§10:
covers are **thematic art** (`alt=""`, decorative), never a documentary claim
about a specific initiative. Cards prefer the record's own `coverImage`
(spec §4, set in the seed for the demo initiatives) and fall back to the
category art. Replacements must keep the CC0/PDM-only bar and be re-recorded
here.
